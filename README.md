## 🎯 О проекте

`lecture` — это веб-приложение, которое собирает и структурирует видеозаписи учебных занятий. Проект создан для удобного доступа студентов к материалам прошедших пар: лекций, практик и других онлайн-встреч.

Страница автоматически подгружает доступные записи и предоставляет простой интерфейс для их просмотра. Обработка новых записей происходит в ночное время для экономии ресурсов.

## 🚀 Быстрый старт

Проект не требует установки — это сайт!

```bash
(для программистов)
# Клонируйте репозиторий
git clone https://github.com/RI-161123/lecture.git

# Перейдите в папку проекта
cd lecture

# Откройте index.html в браузере
# (или запустите локальный сервер, например:)
python -m http.server 8000
```

После этого откройте `http://localhost:8000` в браузере.
